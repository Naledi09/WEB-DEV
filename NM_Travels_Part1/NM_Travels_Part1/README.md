## Project Overview
NM Travels is a fictional transport company established in 2024 for an academic website project. The proposed business provides airport transfers, intercity shuttle services, commuter transport and private group rides.

## Website Goals and Objectives
1. Allow visitors to view routes and schedules.
2. Allow users to submit online seat-booking requests.
3. Generate qualified private charter enquiries.
4. Build trust through transparent service and fleet information.
5. Provide contact and multi-location information.

## Key Features
- Responsive navigation
- Route search demonstration
- Filterable route table
- Booking request form
- Private charter enquiry form
- Fleet page
- Company history and mission/vision
- Two-location contact/service area
- JavaScript validation and interactionS
